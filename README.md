# EdgeWorkspace

屏幕右缘唤出的轻量 Windows 工作区面板：文件收纳 + Markdown 白板便签墙。
由 Rainmeter 皮肤（v2.3，保留在 `Documents\Rainmeter\Skins\Edge_Workspace`）迁移而来，
迁移原因与完整决策记录见仓库提交历史。

## 功能

- **贴边唤出**：鼠标贴屏幕右缘 8px 内自动滑出（右缘被应用窗口盖住时不打扰）；移开/点击面板外自动收回；📌 可钉住常驻
- **拖拽唤出**：从任何窗口（包括最大化的资源管理器）按住文件拖到屏幕右缘 = 面板自动滑出并切到【全部】，松手即移入工作区（支持多选）
- **快捷键**：`Ctrl+Shift+Z` 无视当前焦点随时呼出，自动置顶抢前台；再按收起
- **实时文件网格**：工作区（`D:\Workspace_Temp`）内容实时镜像，名称/大小/日期
- **缩略图**：图片直接显示内容；视频显示第 1 秒画面并带 ▶ 徽标；浏览器解不了的格式（HEIC/PSD 等）回退图标
- **分类 Tab**：全部 / 文件夹 / 文档 / 图片 / 视频 一键过滤
- **白板便签墙**（无限量）：卡片即渲染后的 Markdown（表格/任务列表/代码块/单换行换行），点标题改名、点删除
- **独立便签窗口**：单击卡片打开真窗口——可拖动、可最大化全屏、在任务栏有图标；默认查看态（渲染视图），点「编辑」进源码编辑，Ctrl+S 保存回查看态，Esc 取消
- **右键系统菜单**：文件上右键 = Windows 原生菜单（删除/剪切/重命名）
- **安全**：便签 Markdown 经 DOMPurify 消毒渲染；便签内链接在系统浏览器打开，不导航走面板

## 快捷键

| 键 | 作用 |
|---|---|
| `Ctrl+Shift+Z` | 显示/隐藏面板（无视焦点，置顶呼出） |
| 滚轮 | 文件网格翻页 |
| 📌 | 钉住（禁用自动收起） |
| 便签窗口内 `Ctrl+S` | 保存并回到查看态 |
| 便签窗口内 `Esc` | 取消编辑 |

## 构建与运行

需要 [.NET 8 SDK](https://dotnet.microsoft.com/download/dotnet/8.0) 与 WebView2 运行时（Win10/11 一般自带）。

```
cd src/EdgeWorkspace
dotnet run -c Release
```

便签数据在 exe 同目录 `notes/` 下（每便签一个 `.txt` Markdown 源码 + `index.json` 标题索引）；
注意 `dotnet clean` 或手删 `bin` 会连便签数据一起删掉。

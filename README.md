# EdgeWorkspace

屏幕右缘唤出的轻量 Windows 工作区面板：文件收纳 + 白板便签墙。
由 Rainmeter 皮肤（v2.3，保留在 `Documents\Rainmeter\Skins\Edge_Workspace`）迁移而来，
迁移原因与完整决策记录见仓库提交历史。

## 功能

- **贴边唤出**：鼠标贴屏幕右缘 8px 内自动滑出；移开/点击面板外自动收回；📌 可钉住常驻
- **快捷键**：`Ctrl+Shift+Z` 随时开/关
- **实时文件网格**：工作区（默认 `F:\Workspace_Temp`）内容实时镜像，图标/名称/大小/日期，图片视频直接显示缩略图
- **分类 Tab**：全部 / 文件夹 / 文档 / 图片 / 视频 一键过滤
- **拖入收纳**：从资源管理器拖文件到面板 = 移入工作区（支持多选）
- **白板便签墙**：6 张便签，点开直接编辑，自动保存，重启不丢；右键清空
- **右键系统菜单**：文件上右键 = Windows 原生菜单（删除/剪切/重命名）

## 快捷键

| 键 | 作用 |
|---|---|
| `Ctrl+Shift+Z` | 显示/隐藏面板 |
| 滚轮 | 文件网格翻页 |
| 📌 | 钉住（禁用自动收起） |

## 构建与运行

需要 [.NET 8 SDK](https://dotnet.microsoft.com/download/dotnet/8.0) 与 WebView2 运行时（Win10/11 一般自带）。

```
cd src/EdgeWorkspace
dotnet run -c Release
```
